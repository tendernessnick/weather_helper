# Weather Helper 优化方案 · 2026-11-14

## 现状与目标

现有产品是 React 19 + TypeScript + Vite PWA、FastAPI + SQLite，CloudBase 单容器部署；覆盖 57 个球场、SWIRLS 临近预报、Open-Meteo、校正/融合、众包上报、打卡、提醒、统计和管理页。本轮保留架构及现有功能，优先改善从找场到决定出发的路径。

1. **数据可信**：显式报告数据新鲜度，过期或缺失数据不显示低风险结论；修正排行榜中位数及时间参数。融合数值说明为启发式风险参考，未经独立校验不得当作整场降雨概率。
2. **按场次决策**：详情选择开打时间和打球时长，按实际窗口展示最高风险、覆盖情况、更新时间；保留预警、上报、历史评分和提醒。
3. **找场与回访**：增加本机收藏、地区筛选和搜索清除，保留 A–Z；排行榜切换时间避免乱序响应，提供空态与重试。
4. **移动与弱网**：导航适应窄屏，键盘焦点可见，GET 超时/取消，断网说明与恢复，按页拆包。
5. **验收交付**：后端完整测试、前端构建、针对错误路径/时区/乱序/收藏的浏览器回归；保存可重复脚本与结果，审核后提交并推送 GitHub。
